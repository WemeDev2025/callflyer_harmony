# 瞻养乐园 - 微信小程序

## 项目简介

瞻养乐园是一个专业的养老服务平台微信小程序，为老年人和护理人员提供便捷的服务对接平台。

## 功能特性

### 1. 首页功能
- **垂直布局设计**：采用现代化的垂直布局，用户体验友好
- **顶部轮播图**：支持左右切换，展示平台特色服务
- **H5页面集成**：轮播图点击可打开指定的H5页面
- **服务卡片**：5个主要服务入口，清晰直观

### 2. 我要找活功能
- **个人信息编辑**：姓名、联系电话、头像上传
- **证件管理**：身份证、健康证、养老护理员资格证书、急救员证书（可选）
- **技能标签**：失智照护、失能照护、术后/康复照护、慢性病照护、安宁疗养
- **工作卡预览**：生成专业的工作名片，展示个人专业信息

### 3. 养老请人功能
- **性别选择**：男/女/不限
- **证件要求**：灵活的证件要求设置
- **服务需求**：多种护理服务类型选择
- **详细描述**：其他特殊要求的文字描述
- **联系方式**：发布者联系信息

### 4. 预览工作卡功能
- **专业展示**：美观的工作卡设计
- **信息完整**：证件、技能、联系方式等全面展示
- **分享功能**：支持保存到相册、分享给朋友、复制链接
- **编辑功能**：可随时修改工作卡信息

## 技术架构

### 页面结构
```
pages/
```

## 注意事项

1. **数据安全**：所有用户数据存储在本地，注意数据备份
2. **权限管理**：头像上传需要用户授权
3. **网络请求**：H5页面需要配置业务域名
4. **兼容性**：确保在不同设备上的显示效果

## 性能优化
